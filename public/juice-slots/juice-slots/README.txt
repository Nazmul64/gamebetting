Juice Slots - edit guide
index.html      : page structure and text (INFO/Settings labels)
css/style.css   : colours (top :root variables), sizes, fonts
js/game.js      : PAY (payouts), LINES (paylines), BETS, st (credit/bet), KEYS (symbols)
images/*.svg    : the 7 symbol images (strawberry, banana, grape, juice=wild, cup, egg, org)
To use PNG/JPG: put files with same names in images/ and set IMG_EXT in js/game.js.
Open index.html in a browser to play.
